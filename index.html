One-time Supabase setup
Step 1

Create a free Supabase project

Go to supabase.com → New Project. Choose a name, set a database password, pick a region close to you (e.g. EU West).

Step 2

Create the database tables

In your Supabase project go to SQL Editor and run this SQL:

-- Enable UUID extension create extension if not exists "uuid-ossp"; -- John's readings create table john_readings ( id uuid primary key default uuid_generate_v4(), user_id uuid references auth.users not null, recorded_at timestamptz default now(), weight numeric(5,1), systolic int, diastolic int, pulse int, blood_sugar numeric(4,1), food text, context text[], notes text, created_at timestamptz default now() ); alter table john_readings enable row level security; create policy "own rows" on john_readings using (auth.uid() = user_id) with check (auth.uid() = user_id); -- Vanitha's readings create table vanitha_readings ( id uuid primary key default uuid_generate_v4(), user_id uuid references auth.users not null, recorded_at timestamptz default now(), weight numeric(5,1), systolic int, diastolic int, pulse int, food text, context text[], notes text, created_at timestamptz default now() ); alter table vanitha_readings enable row level security; create policy "own rows" on vanitha_readings using (auth.uid() = user_id) with check (auth.uid() = user_id);
Step 3

Paste your project credentials

In Supabase go to Project Settings → API. Copy the Project URL and the anon / public key.
